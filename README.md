# Projeto_Aerion_DesignInteracao
Simulação acadêmica de um centro de comando para defesa de perímetro. Um radar varre os 360°, o operador seleciona contatos, calcula uma rota de interceptação e decide sob pressão a partir de alertas por nível de ameaça.
Projeto acadêmico. Todos os dados são fictícios e gerados localmente. Nada aqui representa um sistema real de defesa.
